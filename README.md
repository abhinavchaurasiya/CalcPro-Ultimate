# CalcPro Ultimate 🧮

A modern advanced calculator built with HTML, CSS and JavaScript.

## 🚀 Features

- Basic arithmetic calculations
- Scientific calculator mode
- Currency converter
- Calculation history
- Dark/Light theme
- Responsive design
- Clean and modern UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
